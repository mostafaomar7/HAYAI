وعليكم السلام، وجمعة مباركة.

الملف المرفق hayai-container-import.json فيه الحاوية جاهزة للاستيراد، مبنية على الأحداث اللي الموقع بيبعتها بالظبط. دي خطوات الاستيراد والمراجعة والنشر.

٢. الاستيراد

  1. Admin ← Import Container ← Choose container file ← اختاروا hayai-container-import.json.
  2. Choose workspace: New، وسمّوه initial build.
  3. Choose an import option: Merge ← Rename conflicting tags, triggers, and variables.
  4. Confirm. Tag Manager هيعرض ملخص بالعدد اللي هيتضاف، المفروض يطابق جدول القسم ١.

٤. المراجعة قبل النشر — بزرار Preview

  1. افتحوا https://hayaihealthcare.com/ar في الـ Preview. قبل الموافقة على البانر: مفيش أي تاج من GA4 أو Ads أو Clarity يشتغل.
  2. وافقوا على الكل: Google tag - GA4 يشتغل، و Clarity يشتغل على الرئيسية.
  3. افتحوا صفحة الطوارئ والعناية المركزة: Clarity ما يشتغلش.
  4. اضغطوا زرار الواتساب: GA4 - whatsapp_click و GAds - Conv - WhatsApp يشتغلوا مرة واحدة.
  5. في صفحة الطوارئ اضغطوا الواتساب: GA4 يشتغل، و Ads لأ (Block - Sensitive).
  6. افتحوا الموقع بـ ?hayai_team=1: تاجز Ads و Clarity ما يشتغلوش.

٥. النشر

  1. Submit ← Publish and Create Version، باسم v1 initial build وسطر وصف.
  2. Admin ← Export Container للنسخة المنشورة، وابعتوا لنا الملف نحفظه مع المشروع.
  3. بلّغونا بعد النشر، ونتأكد مع بعض إن الأرقام بدأت توصل لـ Analytics و Ads.

٦. صلاحية النشر التانية

أيوه، Hayai.healthcare@gmail.com هو الإيميل المتفق عليه، ومش محتاجين حد تالت. يتضاف من Admin ← User Management بصلاحية Publish على الحاوية و Administrator على الحساب، ويتفعّل عليه التأكيد بخطوتين زي حساب د. جنة.

لو أي خطوة ما مشيتش زي المكتوب، ابعتولنا صورة من الشاشة. شكرًا ليكم.
